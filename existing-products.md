## NPM Packages

- [chroma.js](https://gka.github.io/chroma.js)  
  A widely-used, zero-dependency color library (~13.5 kB) supporting extensive color conversions and manipulations​. Chroma.js can parse colors from many formats (hex, RGB(A), named colors, etc.), adjust them (e.g. .darken(), .saturate()), convert between color models, and generate color scales via linear or Bézier interpolation in various color spaces​. It includes helpers for data visualization palettes (e.g. cubehelix scales)​. Its rich feature set makes it versatile for tasks from palette generation to color analysis, though it is larger in size than some newer libraries​.
