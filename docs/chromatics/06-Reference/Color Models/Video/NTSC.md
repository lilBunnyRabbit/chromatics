# NTSC

> The first widely deployed color television standard (USA, 1953) — defines color encoding for analog TV using YIQ separation, backward-compatible with black-and-white TV.

## Overview
NTSC is the first widely deployed color television standard, introduced in the USA in 1953. It defines analog color encoding for North America and Japan using YIQ separation (luma plus two chroma channels), and was designed to remain backward-compatible with existing black-and-white television receivers.

## Characteristics
- **Key specifications:**
  - 525 scan lines, 30 fps (29.97 interlaced).
  - Uses the YIQ color model (luma + two chroma channels).
  - Color subcarrier at 3.579545 MHz.
  - Quadrature amplitude modulation (QAM) for color encoding.
- **Key strengths:**
  - Backward compatible with B&W TV.
  - Dominated North America, Japan, South Korea, and parts of South America.
  - Foundation for all subsequent video color encoding standards.
- **Coverage:** USA, Canada, Mexico, Japan, South Korea, Philippines.
- **Superseded by:** Digital TV (ATSC in North America, ISDB in Japan).
