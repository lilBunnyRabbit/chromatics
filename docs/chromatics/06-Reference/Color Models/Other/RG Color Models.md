# RG Color Models

> Simplified 2-channel color models using only Red and Green -- historically used in early computing, now mainly academic interest.

## Overview
RG color models are simplified models using only the red and green channels. They were historically used in early computing and are now primarily of historical or academic interest.

## Characteristics
- **Best for:** Academic study of color vision, historical computing.

## Conversions
- **Derived from:** RGB (drop B channel).
- **Converts to:** RGB (with B=0).

## Chromatics API
**Note:** Historical/academic. No API -- subsumed by `RGChromaticity`.
