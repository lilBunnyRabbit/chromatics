# UVW

> A historical CIE color space (1964) — the first attempt at perceptual uniformity, precursor to CIELUV. Largely obsolete.

## Overview
UVW (CIE 1964 U*V*W*) is a historical CIE color space that extends the CIE system as the first attempt at perceptual uniformity and a precursor to CIELUV. It is largely obsolete today and is of interest mainly for historical reference and for comparing older and modern perceptual color spaces. It was superseded by CIE Luv in 1976.

## Characteristics
- First attempt at perceptual uniformity in the CIE system
- Precursor to CIELUV; largely obsolete
- **Best for:** Historical reference, understanding the evolution of perceptual color spaces

## Conversions
- **Derived from:** CIE XYZ
- **Superseded by:** CIE Luv (1976)

**Note:** Historical (1964). No API — include as conversion target only for completeness.
