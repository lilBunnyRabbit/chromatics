# ANPA

> The American Newspaper Publishers Association color system — 300 spot colors designed for newsprint paper stock; largely historical.

## Overview
ANPA is the American Newspaper Publishers Association color system, defining 300 spot colors specifically designed for newsprint paper stock. It was originally developed by the American Newspaper Publishers Association to standardize color reproduction in print media. The system is largely historical today.

**Best for:** Historical newspaper printing reference.

## Notation & Structure
300 spot colors selected for reproduction on newsprint paper stock.

## Usage
Newspaper printing; standardizing color reproduction in print media. Largely historical.

## Chromatics API
Historical newspaper system. No active API.
