# DIN 6164

> A German color order system based on CIE colorimetry — mathematically rigorous, organizing colors by Hue (T), Saturation (S), and Darkness (D) with uniform perceptual steps.

## Overview
DIN 6164 is a German color order system based on CIE colorimetry. It is mathematically rigorous and scientifically founded, organizing colors by Hue (T), Saturation (S), and Darkness (D) with uniform, perceptually equal hue steps. It is a DIN standard (Deutsches Institut für Normung), used in German industry, particularly coatings and textiles.

**Best for:** German industrial color specification, scientific color ordering.

**Converts to:** CIE XYZ, CIE Lab (via defined formulas).

## Notation & Structure

| Component | Full Name | Range | What it controls |
|-----------|-----------|-------|------------------|
| `T` | Farbton (Hue) | 1–24 | Hue position (24 principal hues) |
| `S` | Sättigung (Saturation) | 0–max (varies) | Color intensity |
| `D` | Dunkelheit (Darkness) | 0–max (varies) | How dark the color is |

## Usage
German industrial color specification, particularly coatings and textiles; scientific color ordering. Based on CIE colorimetry (scientifically founded), with perceptually equal hue steps.
