# Werner's Nomenclature of Colours

> A pioneering color naming system (Patrick Syme after Abraham Werner, 1814) describing 110 named colors with examples from the mineral, vegetable, and animal kingdoms — famously used by Charles Darwin.

## Overview
Werner's Nomenclature of Colours is a pioneering color naming system, published in 1814 by Patrick Syme building on the work of Abraham Werner. It describes 110 named colors, each illustrated with examples drawn from the mineral, vegetable, and animal kingdoms. It is one of the first systematic color naming efforts and a beautiful historical artifact of natural philosophy, now freely available as a digitized reference.

**Key strengths:**
- One of the first systematic color naming efforts.
- Charles Darwin used it aboard HMS Beagle to describe specimens.
- Beautiful historical artifact of natural philosophy.
- Now freely available as a digitized reference.

**Best for:** Historical reference, natural history color description, design inspiration.

## Notation & Structure
**110 colors** organized into: Whites, Greys, Blacks, Blues, Purples, Reds, Oranges, Yellows, Greens, Browns.

Each color entry includes:
- The color name and a painted swatch.
- A mineral example (geological reference).
- A vegetable example (botanical reference).
- An animal example (zoological reference).

## Usage
Used historically for natural history color description — most famously by Charles Darwin aboard HMS Beagle to describe specimens. Today valued for historical reference and design inspiration.

## Chromatics API
**Type:** `CatalogSystem`

**Static methods:**
- `Werner.lookup('Arterial Blood Red')` -> `Color`
- `Werner.nearest(color)` -> `{ name, mineral, vegetable, animal, color }`

**Unique value:** Historical color naming with natural world references. Fun feature for the webapp.
