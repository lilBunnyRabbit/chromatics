# Hexachrome

> Pantone's 6-color printing process (1995, discontinued 2008) — CMYK + Orange + Green for ~90% Pantone spot color reproducibility vs ~50% with CMYK alone.

## Overview
Hexachrome was Pantone's six-color printing process, introduced in 1995 and discontinued in 2008. It added Orange and Green inks to the standard CMYK set (CMYK + O + G) to extend the gamut of traditional CMYK printing, achieving roughly 90% Pantone spot color reproducibility versus about 50% with CMYK alone. Modern "expanded gamut" (CMYKOGV) printing is its spiritual successor.

**Best for:** Historical reference; understanding expanded gamut concepts.

## Notation & Structure
Six-color process: CMYK + Orange (O) + Green (G).

## Usage
Extended-gamut process printing for high-fidelity reproduction of Pantone spot colors. Discontinued in 2008; succeeded conceptually by modern expanded gamut (CMYKOGV) printing.

## Chromatics API
Discontinued (2008). Included as reference. No active API.
