# AS 2700

> The Australian Standard for colors — defines ~240 colors for architecture, building, and industrial applications across Australia and New Zealand.

## Overview
AS 2700 is the Australian Standard for colors, defined under Standards Australia. It specifies approximately 240 colors used in architecture, building, and industrial applications across Australia and New Zealand. It is a mandatory reference for Australian government and infrastructure projects.

**Best for:** Australian architecture, government projects, Australian/NZ industrial specification.

**Converts to:** CIE Lab (measured values published), approximate sRGB.

## Notation & Structure
Color coding uses a letter prefix (color group) + a 3-digit number, e.g., **G61 = "Sleeperwood"**.

**Color groups:**

| Prefix | Group |
|--------|-------|
| B | Blue |
| BN | Brown |
| G | Green |
| GY | Grey-Yellow |
| N | Neutral |
| P | Purple |
| R | Red |
| T | Teal |
| X | Yellow/Cream |
| Y | Yellow |

## Usage
Architecture, building, and industrial applications across Australia and New Zealand. Mandatory reference for Australian government and infrastructure projects. Physical color chips available. Cross-referenced with Munsell and CIE Lab values. Defined under Standards Australia.

## Chromatics API
**Type:** `CatalogSystem`

**Static methods:**
- `AS2700.lookup('G61')` -> `Color`
- `AS2700.nearest(color)` -> closest AS match
