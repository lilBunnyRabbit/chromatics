# CNS

> The Chinese National Standard color system — standardized colors for industrial and governmental use across mainland China and Taiwan, based on Munsell.

## Overview
CNS (Chinese National Standard) defines standardized colors for industrial and governmental use across mainland China and Taiwan. It is built on the Munsell color system framework and serves as official government and industrial color standards for Greater China.

**Best for:** Chinese/Taiwanese industrial specification, government projects, export to Chinese markets.

**Converts to:** Munsell (basis), CIE Lab, approximate sRGB.

## Notation & Structure
Based on the Munsell color system framework.

**Key standards:**
- **CNS 13076** (Taiwan): National standard color system based on Munsell.
- **GB/T 15608** (mainland China): Chinese color naming and specification standard.

## Usage
Manufacturing, signage, and government procurement across mainland China and Taiwan. Official government and industrial color standards for Greater China.

## Chromatics API
**Type:** `CatalogSystem`

**Static methods:**
- `CNS.lookup(code)` -> `Color`
- `CNS.nearest(color)` -> closest CNS match
