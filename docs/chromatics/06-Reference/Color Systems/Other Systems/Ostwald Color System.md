# Ostwald Color System

> Wilhelm Ostwald's system (1916) that organizes colors by hue, white content, and black content (C + W + K = 100%) — historically influential, largely superseded.

## Overview
A historical color system developed by Wilhelm Ostwald (1916) for systematically classifying and comparing colors. It organizes colors by hue, white content (W), and black content (K), where full color content (C) plus white plus black sum to 100% (C + W + K = 100%). Historically influential, it has been largely superseded by modern systems.

**Legacy:** The HWB color model is essentially a modernized Ostwald approach.

**Best for:** Historical reference, understanding color system evolution.

## Notation & Structure
A color is specified by its hue together with its white content and black content, constrained so that full color content, white, and black always sum to 100% (C + W + K = 100%).

## Usage
Primarily of historical and educational interest for understanding the evolution of color systems. Conceptually the ancestor of the modern HWB model.

## Chromatics API
**Note:** Historical system. No direct API — conceptually the ancestor of HWB. See `HWB` model.
