# Colour Index International

> The global reference database for pigments and dyes — assigns standardized C.I. names and numbers to every commercial colorant (13,000+).

## Overview
Colour Index International is the global reference system for pigments and dyes used across industries to ensure consistent color reproduction. It assigns standardized C.I. names and numbers to every commercial colorant, covering 13,000+ entries.

**Best for:** Chemical colorant specification, pigment procurement, dye formulation.

## Notation & Structure
Naming format: **C.I. [Application] [Color] [Number]**, e.g., "C.I. Pigment Red 170".

## Usage
Chemical colorant specification, pigment procurement, and dye formulation across many industries to ensure consistent color reproduction.

## Chromatics API
Chemical reference database. Out of scope for a color manipulation library. Included as reference only.
