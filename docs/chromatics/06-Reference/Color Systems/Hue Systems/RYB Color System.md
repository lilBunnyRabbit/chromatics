# RYB Color System

> The traditional artist's color wheel built on Red, Yellow, and Blue pigment primaries, predating modern color science.

## Overview

RYB is the traditional subtractive color system used by artists, based on Red, Yellow, and Blue pigments as primaries, with Orange, Green, and Purple as secondaries. It predates modern color science and underlies the classic artist's color wheel.

**Best for:** Art education, traditional painting, and intuitive color theory.

## Notation & Structure

- **Primaries:** Red, Yellow, Blue
- **Secondaries:** Orange, Green, Purple
- Subtractive mixing model based on pigments rather than light.

## Usage

Primarily used in art education, traditional painting, and intuitive color theory teaching.
