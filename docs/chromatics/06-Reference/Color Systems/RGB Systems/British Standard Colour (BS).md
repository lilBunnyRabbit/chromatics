# British Standard Colour (BS)

> A standardized UK color system (BS 381C / BS 4800 / BS 5252) for government, military, and industrial use.

## Overview
The British Standards Institution color system is a standardized color system used in the UK for industrial and design applications. It spans the BS 381C, BS 4800, and BS 5252 palettes, providing standardized colors for UK government, military, and industrial use. It is best suited for UK building specification, defense equipment, and British industrial standards.

## Notation & Structure
Colors are specified by standard codes referencing the relevant BS palette (e.g. `381C-538`).

## Usage
Used in the UK for industrial and design applications — building specification, defense/military equipment, and British industrial standards.

## Chromatics API

**Type:** `CatalogSystem`

**Static methods:**
- `BSColour.lookup('381C-538')` -> `Color`
- `BSColour.nearest(color)` -> closest BS match
