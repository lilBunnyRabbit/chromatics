# DIC Color System

> DIC Corporation's proprietary Japanese spot color system, comparable to Pantone, for printing, packaging, and design.

## Overview
The DIC Color System is a proprietary color system developed by DIC Corporation (Japan) for packaging, design, and printing applications. It is a major spot color system for Japanese and Asian printing and packaging, comparable to Pantone. It is best suited for Japanese printing, Asian packaging design, and spot color specification.

## Notation & Structure
Colors are specified by DIC code identifiers.

## Usage
Used for Japanese printing, Asian packaging design, and spot color specification, as well as general packaging and design applications.

## Chromatics API

**Type:** `CatalogSystem`

**Static methods:**
- `DIC.lookup(code)` -> `Color`
- `DIC.nearest(color)` -> closest DIC match
