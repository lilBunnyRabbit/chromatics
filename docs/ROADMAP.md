4. [-] **Package on a branch** (`feat/color-package`): `packages/chromatics` + Bun workspaces
   - [x] Scaffold (2026-10-19): base class, router, exact matrix generator, Vitest on both engines

     - references: CSS Color 4 + WPT + Ottosson (+ Wikipedia for HSV only), and the culori cross-check grid

   - [x] Per-model subpath exports (2026-10-19, ADR-007): generated by `bun run exports`, checked by a test
   - [x] Wide-gamut RGB (2026-10-19, ADR-010 family 1): `A98Rgb`, `ProphotoRgb`, `Rec2020`, `LinearDisplayP3`, with the full matrix, exact matrices and WPT references
   - [ ] Remaining wide-gamut RGB (ACES and others: names and sources to grill)

   - [x] `@lilbunnyrabbit/optional` 1.1.0 published (2026-10-19, npm trusted publishing)
